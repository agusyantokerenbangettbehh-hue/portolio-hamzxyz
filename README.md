# Portfolio Personal

Template portfolio modern, responsif, dan tanpa framework.

## Cara menjalankan di VS Code

1. Buka folder ini di VS Code.
2. Buka `index.html` menggunakan ekstensi **Live Server**, atau klik dua kali file tersebut di browser.
3. Ganti teks `Nama Kamu`, email, tautan sosial, dan isi proyek sesuai data pribadi.

## Struktur

- `index.html` — struktur halaman
- `styles.css` — tampilan, layout, dan responsif
- `script.js` — menu mobile dan interaksi kecil
